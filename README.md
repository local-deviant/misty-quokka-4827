An hour of twelve people's time, and the only thing said was a single word. Built by an AI agent for make.fun's "The Meeting That Should Have Been an Email" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
